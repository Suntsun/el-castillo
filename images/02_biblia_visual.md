- # Biblia visual — El Castillo

  ## Retratos de consejeros del sistema

  ------

  ## Concepto central

  Cada automatización del ecosistema tiene un consejero visual: una entidad que personifica su función. No son héroes ni villanos. Son espíritus administrativos del sistema operativo — competentes, serenos, funcionales, casi burocráticos.

  La sensación que debe transmitir cada retrato: este personaje sabe exactamente lo que hace, lleva siglos haciéndolo, y no necesita demostrarlo.

  ------

  ## Referencias visuales

  | Referencia      | Qué tomar                                                    |
  | --------------- | ------------------------------------------------------------ |
  | Civilization VI | Formato medallón, claridad de retrato, lectura a tamaño pequeño |
  | The Banner Saga | Simplificación visual, silueta limpia, sobriedad             |
  | Arcane          | Tratamiento de iluminación suave, silueta definida           |

  **No es:** concept art cinematográfico, fantasy genérico, MMORPG, anime, hiperrealismo.

  ------

  ## Formato obligatorio

  - **Proporción:** 1:1 cuadrado
  - **Composición:** busto centrado, personaje ocupa 70-80% del encuadre
  - **Marco:** circular tipo medallón, obligatorio en todos los personajes
  - **Fondo:** abstracto minimalista — símbolos funcionales sutiles, texturas geométricas, ninguna escena ni paisaje
  - **Tamaño funcional:** debe leerse perfectamente a 64px (para notificaciones Linux)

  ------

  ## Iluminación

  - Suave, limpia, sin contrastes violentos
  - Frontal o lateral ligera (máximo 30° de ángulo)
  - Sin rim light dramático ni contraluz
  - Debe mantenerse legible en pantallas oscuras y claras

  ------

  ## Nivel de detalle

  - **Medio** — ni minimalismo extremo ni barroquismo
  - Silueta muy clara y reconocible
  - Máximo 3-4 elementos visuales por personaje
  - Iconografía funcional: un objeto, símbolo o atributo que indique la función del rol
  - Sin texturas complejas, sin ropa con mil pliegues, sin fondos recargados

  ------

  ## Arquetipos visuales por función

  | Arquetipo      | Función del sistema                        | Rasgos visuales                                              |
  | -------------- | ------------------------------------------ | ------------------------------------------------------------ |
  | El Guardián    | Seguridad, firewall, cifrado               | Armadura sobria, símbolo de escudo o sello, expresión vigilante |
  | El Archivista  | Logs, backups, almacenamiento              | Túnica estructurada, pergaminos o registros, expresión metódica |
  | El Orquestador | Coordinación, pipelines, encadenado        | Distintivos de mando, mapa o diagrama abstracto, expresión serena |
  | El Explorador  | Red, monitorización, escaneo               | Capa ligera, instrumentos de medición, expresión atenta      |
  | El Heraldo     | Comunicación, notificaciones, bots         | Insignias de mensajería, señales abstractas, expresión eficiente |
  | El Ingeniero   | Builds, mantenimiento, compilación         | Herramientas funcionales discretas, expresión concentrada    |
  | El Oráculo     | IA, análisis, generación de ideas          | Elementos abstractos de conocimiento, expresión contemplativa |
  | El Mayordomo   | Tareas programadas, arranque, modo trabajo | Vestimenta de servicio estructurado, lista o agenda, expresión organizada |
  | El Alquimista  | Traducción, transformación de datos        | Símbolos de conversión, expresión analítica                  |
  | El Centinela   | Temperatura, eventos, watchdog             | Postura alerta, sensores sutiles, expresión vigilante pero tranquila |

  ------

  ## Lo que debe evitarse siempre

  - Poses dinámicas o agresivas
  - Armas grandes o actitud combativa
  - Fondos con escenas, arquitectura detallada o paisajes
  - Partículas mágicas exageradas o efectos de hechizo
  - Estética de videojuego de acción
  - Expresiones exageradas o emocionales
  - Exceso de ornamentación
  - Cualquier elemento que distraiga de la función del personaje
