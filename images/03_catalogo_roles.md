## Orden de generación recomendado

Genera en este orden para establecer el estilo antes de los casos difíciles:

1. `el_arquitecto_del_castillo` — ancla el estilo de todo el proyecto
2. `jefe_de_maquinas` — primer test de consistencia
3. `cronista_errores` — arquetipo archivista base
4. `guardian_secretos` — arquetipo guardián base
5. `heraldo_mensajes` — arquetipo heraldo base
6. A partir de aquí, generar por grupos

---

## Notas de consistencia

- El marco medallón debe ser idéntico en todos (mismo grosor, mismo estilo dorado)
- El fondo abstracto cambia por personaje pero mantiene la misma densidad visual
- Las expresiones nunca son extremas — todos están "en modo trabajo"
- Si dos personajes del mismo arquetipo se parecen demasiado, diferenciarlos por el símbolo funcional, no por la paleta
